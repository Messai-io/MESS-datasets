# Zenodo (data/zenodo/)

Datasets ingested from [Zenodo](https://zenodo.org), CERN's general-purpose
open-science repository. Relevant records are discovered via keyword searches
(see `seed.yaml` → `search_provenance`) and pulled through
`scripts/fetch-zenodo.py`.

## Layout

```
data/zenodo/
  SOURCE.md                this file
  seed.yaml                list of record IDs + search provenance
  catalog.json             aggregated index (generated by build-catalog.py)
  <record-id>/
    metadata.json          /api/records/<id> snapshot
    manifest.json          file list + commit-status per file
    DATASHEET.md           human-readable record card
    files/                 committed small files + derived samples
    .source/               gitignored — full raw downloads
```

## Licensing

Upstream Zenodo records carry their own licenses (most MES-relevant ones are
CC-BY-4.0, CC0-1.0, or MIT). Each record's `DATASHEET.md` states the upstream
license and required attribution. Downstream consumers MUST honor upstream terms
— the repo-level CC-BY-4.0 covers our curation work, not the underlying
datasets.

## API notes

- Endpoint: `https://zenodo.org/api/records/<id>`
- Anonymous rate limit: 60 req/min, 2000 req/hour. Plenty for our scale.
- A `ZENODO_TOKEN` in `.env` raises limits slightly but isn't required.
- File download URL: `file["links"]["self"]`.
- Checksum is reported as `md5:<hex>`; the fetcher verifies after download.

See `docs/sources/zenodo.md` for rerun / refresh guidance.
