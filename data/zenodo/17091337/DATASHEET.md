<div>&nbsp;</div>
<div>-SEM: Scanning electron microscopy</div>

<div>-EIS-FRA: Electrochemical Impedance Spectroscopy-Frequency Response Analysis</div>
<div>-LSV: Linear Sweep Voltammetry</div>
<div>--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------</div>
<div>Description of units:</div>
<div>&nbsp;</div>
<div>--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------</div>
<div>Definiton of codes used to record the data:</div>
<div>&nbsp;</div>
<div>-PVC100%: Membrane containing only PVC.</div>
<div>-DES30%: Membrane containing 30% of DES and 70% of PVC.</div>
<div>-DES50%: Membrane containing 50% of DES and 50% of PVC.</div>
<div>-DES70%: Membrane containing 70% of DES and 30% of PVC.</div>
<div>--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------</div>
<div>&nbsp;</div>
<div>File name structure:</div>
<div>&nbsp;</div>
<div>The following repository contains .zip folders which are distinguished accordingly to the chosen type of analysis.</div>
<div>&nbsp;</div>
<div>&nbsp;A sub-folder labeled "EDX" containing EDX spectra in .text file format named "EDX_Spectra"</div>
<div>&nbsp;A sub-folder labeled "SEM" containing the images of the membranes surface obtained by SEM in .TIFF format named using the codes described above.</div>
<div>&nbsp;A sub-folder labeled "Electrochemical characterization" containing the following sub-folders:</div>
<div>&nbsp;</div>
<div>-A sub-folder labeled "Chronoamperometry" containing the chronoamperometry measurements in .text file format name "Chronoamperometry_measurements"</div>
<div>-A sub-folder labeled "EIS-FRA" containing the Nyquist plot data in .text file format name "FRA_Nyquist"</div>
<div>-A sub-folder labeled "LSV-Polarizations" the Linear Sweep Voltagrams in .text file format name according to the type of membrane (codes described above) and the day when the LSV was performed during the operation period (day 5th, 12nd and 19th).</div>
